# Cyber Lab

A hands-on cybersecurity laboratory for learning by building, testing, documenting, and hardening local systems.

## Labs

- 01-networking — TCP/IP, sockets, ports, and service inspection
- 02-linux — permissions, processes, services, and hardening
- 03-web-security — HTTP, authentication, input validation, and common web flaws
- 04-authentication — sessions, password handling, CSRF, and RBAC
- 05-cryptography — hashing, encryption, keys, and secure usage
- 06-docker-security — containers, privileges, secrets, and socket risks
- 07-logging-monitoring — security events, logs, detection, and response
- 08-writeups — concise evidence-based lab reports

## Rules

All experiments run against local or explicitly authorized systems. Each lab records objective, environment, procedure, observations, mitigation, and lessons learned.
